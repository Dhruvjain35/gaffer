The idea

It coaches itself.

Most assistants make the same mistake twice. This one doesn't.

  1. 01

    It answers, grounded.

    The Player pulls from a verified World Cup knowledge base — never from memory — and cites what it used.

  2. 02

    A referee grades it.

    Every answer is scored for honesty against the evidence and filed to Arize Phoenix. A clean answer is a goal; an unsupported claim is a miss.

  3. 03

    The Gaffer reviews the misses.

    It reads its own game tape through the Phoenix MCP and drills each failure into a regression set.

  4. 04

    It rewrites the playbook.

    A new system prompt is written to fix exactly what failed — kept general, never hard-coded to one question.

  5. 05

    It proves the change.

    Old and new play a scrimmage — two Phoenix experiments, judge-scored, head to head.

  6. 06

    Only a winner ships.

    If the new playbook wins, it's promoted. No human in the loop, no redeploy. If it doesn't, nothing changes.
