The idea

It coaches itself.

Most assistants make the same mistake twice. This one doesn’t.

  1. 1

    Answers, grounded.

    The Player pulls only from a verified World Cup knowledge base and cites what it used — never from memory.

  2. 2

    A referee grades it.

    Every answer is scored for honesty against the evidence and filed to Arize Phoenix. Clean is a goal; an unsupported claim is a miss.

  3. 3

    The Gaffer reviews misses.

    It reads its own game tape through the Phoenix MCP and drills each failure into a regression set.

  4. 4

    It rewrites the playbook.

    A new prompt is written to fix exactly what failed — kept general, never hard-coded to one question.

  5. 5

    It proves the change.

    Old and new play a scrimmage — two Phoenix experiments, judge-scored, head to head.

  6. 6

    Only a winner ships.

    If the new playbook wins it’s promoted — no human, no redeploy. If not, nothing changes.
