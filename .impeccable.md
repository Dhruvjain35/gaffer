## Design Context  (v2 — refined minimal pivot, 2026-06-26)

The previous broadcast "control room" became overstimulating: too much text, too many live elements on one screen, dark-with-glow (the AI-slop tell). Full reset toward **calm, premium, editorial minimalism** — the restraint of Apple / OpenAI / Anthropic, executed for a World Cup concierge.

### Users
Hackathon judges (Arize/Google engineers, poking the live URL) + curious World Cup fans. The interface must read instantly as a *premium product*, not a dashboard and not a chatbot.

### Brand Personality
**Calm · editorial · quietly sophisticated.** A matchday programme redesigned by a serious studio. Confidence through whitespace, not density. The cleverness (it referees + coaches itself) is revealed gently, never crammed.

### Aesthetic Direction
**Light & warm**, by deliberate contrast with the AI-dark-glow reflex. Warm paper/cream surfaces, deep warm ink, ONE restrained accent (deep pitch green). Generous whitespace, large refined type, minimal chrome. Calm motion only (gentle reveals). A **multi-screen** app (Home · Ask · How it works · Venues) with a thin top nav — one job per screen, never everything at once. Trust/observability details live behind **progressive disclosure**, not always-on.
Anti-reference: the prior control-room, any dashboard, dark+neon, dense always-visible telemetry, walls of label text.

### Typography (non-reflex)
- **Display / headlines:** Spectral (serif, 300–500) — editorial, intelligent, warm. Large, tight leading.
- **Body / UI:** Hanken Grotesk (400–600) — clean humanist sans, high readability.
- No monospace as decoration; minimal tiny labels only.

### Design Principles
1. **One job per screen.** Home sells; Ask answers; How-it-works explains; Venues browses. Never combine.
2. **Whitespace is the design.** Big margins, few elements, large type. If in doubt, remove it.
3. **Progressive disclosure of trust.** An answer shows a quiet "verified" line; sources + the trace expand only on intent.
4. **Calm, sparse motion.** Gentle fades/reveals on navigation; no ambient loops, no shockwaves, no live dials.
5. **One accent, used rarely.** Deep green for the few moments that matter (CTA, verified, key numbers). Everything else is ink on paper.
